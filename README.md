# Jakob Holmqvist Larsen — portfolio

Gratis, selvstændig version af den offentlige Adobe Portfolio-side, arkiveret 27. september 2026.

**Live:** https://jakobholmqvist.github.io/

Webstedet består af `index.html`, 19 undersider, `styles.css` og 222 lokale billeder i `assets/`. GitHub Pages udgiver automatisk `main`-branchens rodmappe. Ændringer kan foretages direkte i HTML og CSS uden Adobe-abonnement.

Den fulde kildepakke med arkivmetadata er gemt separat. Siderne er rekonstrueret ud fra den offentligt viste hjemmeside; det er ikke en redigerbar eksport fra Adobes Portfolio-editor.
